# 宝可驾 · 交规地牢

宝可梦主题的驾考答题爬塔游戏:一边答题攒能量,一边用技能卡牌打怪闯关。融合「科目一学习」与「卡牌爬塔」的休闲游戏。

## ✨ 功能特性

- **卡牌战斗**:答题链答对攒能量 → 出牌阶段打出技能卡 → 泄能攻击 → 敌方反击,80+ 张技能卡、5 大类型
- **上阵队伍**:图鉴中自由选择已解锁的宝可梦上阵(最多 3 只),每只拥有独立血量,战斗可切换、阵亡自动换人
- **宝可梦收集**:1010 只宝可梦,5 种精灵球按稀有度概率捕获,捕获后加入图鉴与队伍
- **随机爬塔**:每层随机生成地图节点(战斗/精英/BOSS/商店/营地/事件/宝箱),BOSS 击败进入下一层,无限闯关
- **科目一模拟考试**:100 题 / 45 分钟 / 90 分合格,支持跳题、标记、交卷判分
- **学习中心**:错题本自动记录答题错误,可针对性巩固练习
- **初始选择**:开局在妙蛙种子、小火龙、杰尼龟中三选一
- **技能抽卡 & 牌组构建**:养成金币抽取技能卡,自由搭配 12 张上限的出战牌组
- **全局养成**:生命 / 攻击升级,爬塔收益跨局积累
- **题库导入**:支持导入自定义题库
- **存档兼容**:`dungeonDrive_*` localStorage 键,旧存档无缝续玩

## 🎮 玩法

1. 点击「新的冒险」,选择初始宝可梦
2. 在地图上选择路径前进,遭遇战斗
3. 战斗中答题(答对 +1 能量),能量够后进入出牌阶段打技能卡
4. 击败敌人可捕获宝可梦、获得奖励卡
5. 不断提升层数,挑战更强的 BOSS,冲击最高分

## 🛠 技术栈

- **Next.js 16**(App Router, Turbopack)
- **React 19** + **TypeScript**
- **zustand 5** 状态管理(纯客户端,localStorage 持久化)
- 纯客户端运行,无后端依赖

## 🚀 运行

要求 **Node ≥ 20.9**。

```bash
npm install
npm run dev     # 开发模式 http://localhost:3000
npm run build   # 生产构建
npm start       # 生产运行
```

## 📁 目录结构

```
app/          页面布局与全局样式(globals.css / cards.css)
components/   16 个屏幕组件 + 弹窗/提示 UI
lib/          游戏逻辑:store / battle / cards / map / save / exam / formulas / audio
data/         1010 只宝可梦、1034 道题、图标、种族值、游戏常量
public/       背景图与 manifest
scripts/      测试脚本(存档兼容 / 布局检查 / 战斗流程)
```

## 🎁 发福利(版本福利)

纯前端无服务端,福利只能随「版本更新」发放:改 [lib/gifts.ts](lib/gifts.ts) 里的 `GIFTS` 表 → `npm run build` 重新部署,玩家下次打开游戏自动到账(每个 id 只发一次,领取记录存 `meta.claimedGifts`)。

```ts
{
  id: "gift-2026-11-10",       // 唯一 id;换新 id 才会再发一次
  title: "版本更新补偿",
  desc: "补偿 500 金币 + 超级球 ×3",
  startAt: "2026-11-10",       // 生效日(含当天),可省略
  endAt: "2026-11-17",         // 截止日(含当天),可省略 = 永久
  items: { gold: 500, balls: { great: 3 }, pkm: [25], cards: ["tackle"] },
  // 可选:三选一礼包(发完 items 后弹出选择框,结果存 meta.giftChoices)
  choice: {
    prompt: "选择一只传说宝可梦",
    options: [
      { id: "kyogre", pkm: [382], desc: "水系 · 高特攻" },
      { id: "groudon", pkm: [383], desc: "地面系 · 高物攻" },
      { id: "rayquaza", pkm: [384], desc: "龙/飞行 · 全能" },
    ],
  },
}
```

- `items` 字段:`gold` 养成金币、`balls` 精灵球、`pkm` 直接收录图鉴、`cards` 解锁技能卡
- `balls` 是**一次性**的:先进 `meta.pendingBalls`,开新局或继续冒险时并入本局,不是每局重发
- `choice` 选中的宝可梦会入库,队伍有空位时自动上阵;点「稍后再选」会在标题页留入口
- 奖励存在玩家浏览器里,改存档可刷,只适合体验向奖励,别发付费资产
- 需要「指定玩家发放 / 防重复领取」必须加后端(Cloudflare Pages Functions + KV)
